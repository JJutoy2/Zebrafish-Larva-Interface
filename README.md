# Zebrafish Larvae Interface (ZLI) System

## Project Overview
The Zebrafish Larvae Interface (ZLI) is a modular Python framework designed to:
- Elicit and track optokinetic responses (OKR) in larval zebrafish.
- Render real-time animations and stimuli using computer vision.
- Interface zebrafish behavior with a robotic line-following platform.

This repository provides the codebase for the ZLI system along with the data generated by it. Videos of the system in various stages of system development are provided for references along with other relevant documents. The ZLI system is in active development and the codebase shared here is mainly educational to understand the structure and interactions between modules. The codebase is likely to change but the concepts behind them will be intact ie: eye tracking through thresholding -> contouring -> ellipse fitting.

## Installation

1. **Clone the repository**  
   ```bash
   git clone https://github.com/JJutoy2/Zebrafish-Larva-Interface.git
   cd Zebrafish-Larva-Interface
   ```

2. **Create a virtual environment**  
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```

## Directory & Module Breakdown

- **Animations**  
  - `animations.py` – core animation loop and canvas setup  
  - `okr_animation.py` – closed-loop OKR-driven animations  
  - `rotating_static_animation.py` – static rotation stimuli  
  - `okr_sin.py` – sinusoidal velocity profiles for OKR  

- **Vision & Filtering**  
  - `hsv_tool.py` – HSV color space utilities  
  - `cv2_filters.py` – basic OpenCV filters (blur, threshold)  
  - `*_filter_stack.py` – composite filter stacks (alignment, color-track, fish-eye, etc.)

- **Camera Interfaces**  
  - `camera_stream.py` – generic video capture pipeline  
  - `ximea_tools.py` – utilities for Ximea camera control  
  - `cv2_tools.py` – OpenCV capture helpers  

- **Data Processing**  
  - `eye_calibration.py` – eye angle calibration routines  
  - `filter_stack_color_track.py` – color-based tracking pipeline  
  - `processing.py` & `ssh_processing.py` – data logging and remote execution  

- **Hardware & Robot Control**  
  - `pi_car_interface.py` – send movement commands to Raspberry Pi robot  

- **Configuration Loader**  
  - `env_tools.py` – centralized environment variable parsing

## Usage Examples

### Start a basic OKR animation
```python
from animations import animate_canvas
from okr_animation import OKRAnimationData

canvas, anim = animate_canvas(OKRAnimationData())
canvas.run()
```
